# CreditDocStruct 관리자 애플리케이션

**신평서 데이터 구조화 프로젝트** — 비개발자가 브라우저에서 **미분류 라벨을 한 건씩 검수**하고,
등록 라벨을 관리하며, **신용등급·재무지표 추출 결과를 조회·엑셀 다운로드**하는 도구입니다.

## 필요 사항

- **Python 3.11 64-bit** ([python.org](https://www.python.org/downloads/))
- **SQLite는 Python에 포함**되어 있어 별도 설치가 필요 없습니다.

## 설치 (최초 1회)

1. `admin\setup_admin.bat` 을 더블클릭합니다.
2. "설치가 완료되었습니다." 메시지가 나오면 닫습니다.

## 실행 (평소)

1. `admin\run_admin.bat` 을 더블클릭합니다.
2. 브라우저에서 관리 화면이 열립니다 (`http://localhost:8501`).

## 화면 구성

| 메뉴 | 설명 |
|------|------|
| **검수하기** | 발견된 라벨을 한 건씩 확인하고 상품에 등록하거나 제외 |
| **등록된 라벨** | 상품별 등록 라벨 요약·검색·추가·삭제 |
| **작업 이력** | 등록·제외·복원 작업을 사람이 읽는 문장으로 확인 |
| **결과 조회** | `result/*.json` 요약 조회, 필터, 상세, 엑셀/JSON 다운로드 |

### 검수하기

1. 기본 모드는 **한 건씩 검수**입니다. (전체 목록은 탐색용)
2. 추천 상품을 참고해 **등록할 상품**과 **등록할 라벨**을 확인합니다.
3. **이 상품으로 등록** → 확인 후 YAML에 반영되고 다음 항목으로 이동합니다.
4. **상품 라벨 아님** → 확인 후 제외 목록으로 옮깁니다.
5. **다음에 검수** → 상태는 그대로 두고 다음 항목만 봅니다.

사이드바에서 현황(대기/승인/제외), 신평사·회사명·발견 기간 필터를 사용할 수 있습니다.

### 결과 조회

1. 결과 JSON 파일을 선택합니다.
2. 처리상태·신평사·상품·실패 사유·회사명/파일명으로 필터합니다.
3. 표에서 요약을 확인하고, 문서를 고르면 상세(실패 사유·전체 등급·원본 레코드)를 봅니다.
4. **엑셀로 다운로드**는 현재 필터 결과만 내려받습니다.

## 사내 서버에서 실행

한 대의 PC에서 `run_admin.bat`을 실행한 뒤, 다른 사용자는 브라우저만 쓰면 됩니다.

- 서버 PC IP: `http://<서버주소>:8501`
- 외부 접속이 필요하면 `run_admin.bat` 안의 안내대로 `--server.address 0.0.0.0` 옵션을 사용하세요.

## 할 수 없는 작업 (개발자 전용)

- 새 상품 종류(상품 코드) 만들기
- 정규화·추천·검증 정책 변경 (`common/matching_policy.py`)
- YAML 파일 구조 직접 편집

## 데이터 저장 위치

| 항목 | 경로 |
|------|------|
| 미분류 후보 DB | `admin/data/admin.db` |
| YAML 백업 | `admin/backup/` |
| 추출 결과 | `result/result_YYYYMMDD.json` · `.xlsx` |
| 테마 | `.streamlit/config.toml` |

PDF 추출(`main.py`)을 실행하면 미분류 라벨이 자동으로 `admin.db`에 쌓입니다. 관리자 앱이 꺼져 있어도 저장됩니다.

## 서버 시작 시 YAML 동기화

관리자 앱은 서버 프로세스가 처음 실행될 때 `admin.db`와 현재
`config/instruments.yaml`을 한 번 동기화합니다.

- 검수 대기 라벨이 YAML에 있으면 → 승인 완료
- 승인된 등록 라벨이 YAML에서 제거되면 → 검수 대기로 복구
- 승인 연결 상품이 바뀌면 → 현재 YAML 연결로 갱신
- 제외된 라벨은 변경하지 않음

동기화 상세 숫자는 사이드바 **시스템 정보**에서 확인할 수 있습니다.
서버 실행 중 개발자가 YAML을 직접 변경했다면 관리자 서버를 재시작해야 동기화됩니다.

## 기존 undefined.json 이관 (개발자)

```bat
cd CreditDocStruct\CreditDocStruct
.venv\Scripts\python.exe -m admin.services.migrate_undefined_json --source admin/undefined.json
```

이관 후 `admin/` 폴더의 구 `undefined.json`은 더 이상 사용하지 않습니다.
