##### 운영 가이드

###### 1. 이 시스템이 하는 일

신용평가서 PDF에서 **신용등급**과 **주요 재무지표**를 읽어 결과 파일(JSON·Excel)로 남깁니다.  
상품 이름은 미리 정해 둔 **상품 사전**(표준 분류 ↔ 원문 표현)에 맞춰 붙입니다.  
사전에 없는 표현·등급이 애매한 건·파일이 깨진 건은 **확인 필요**로 모읍니다.  
공개 Excel에는 **분류에 성공한 건만** 나갑니다.

###### 2. 일상 운영 루프

1. PDF를 입력 폴더에 넣고 추출을 실행한다.
2. **결과 조회**에서 성공·부분성공·실패를 훑는다.
3. **확인 필요**에서 예외 유형을 확인한다.
4. 미분류 라벨이면 **상품 사전**에 원문 표현을 추가한 뒤 **추가**로 저장한다.
5. 같은 PDF를 다시 추출해 반영 여부를 확인한다.
6. 필요 시 Excel을 내려받아 업무에 사용한다.

###### 3. 탭별 사용법

| 탭 | 하는 일 |
|----|---------|
| 결과 조회 | 결과 파일 선택, 신평사·회사 필터, 신용등급·재무지표 확인, Excel 다운로드 |
| 확인 필요 | 예외 목록 확인(읽기 전용). 승인·거절 버튼 없음 |
| 상품 사전 | 표준 상품별 원문 라벨 조회·추가·(관리자 추가분만) 삭제 |
| 운영 가이드 | 이 문서 읽기 |

###### 4. 확인 필요 — 예외별 조치

| 유형 | 조치 |
|------|------|
| 미분류 상품 행 | 상품 사전에서 해당 원문 라벨을 입력 → **추가** → 재추출 |
| 등급 모호/충돌 | 원문 PDF를 보고 수기 보완. 반복되면 개발에 규칙 검토 요청 |
| 재무 표 없음 | 표가 없거나 추출 한계일 수 있음. 필요 시 수기 |
| 파일/텍스트/구조 오류 | PDF를 다시 받거나 손상·암호 여부를 확인 후 재실행 |

###### 5. 상품 사전 — 주의사항

- **기존 라벨은 잠금**입니다. 체크·삭제할 수 없습니다.
- **원문 라벨·메모를 입력한 뒤 추가**를 눌러야 사전에 저장됩니다.
- **삭제**(연한 빨강)는 관리자가 추가한 행만 가능합니다.
- 라벨을 바꾼 뒤에는 **반드시 재추출**해야 결과에 반영됩니다.

###### 6. 혼자 가능 vs 개발 요청

**혼자 가능**

- 결과 확인·Excel 다운로드
- 상품 사전에 원문 표현 추가·관리자 추가분 삭제
- 확인 필요 목록을 보고 재추출

**개발에 요청**

- 새 상품 종류(표준 분류)를 늘리기
- 잠긴(기존) 라벨 수정·일괄 정리
- 추출 규칙·등급 판정 로직 변경
- 반복되는 파일/구조 오류

요청 시 첨부하면 좋은 것: 문제 PDF, 결과 파일명, 회사명, 화면에 보인 예외 유형·원문 라벨.

###### 7. FAQ

**Q. Excel에 안 보이는 회사가 확인 필요에는 있습니다.**  
A. 공개 Excel은 분류 성공 건만 넣습니다. 미분류·실패는 확인 필요에서 다룹니다.

**Q. 상품 사전에 넣었는데 결과가 그대로입니다.**  
A. 저장(**추가**) 후 **추출을 다시** 실행해야 합니다.

**Q. 잠긴 라벨을 지우고 싶습니다.**  
A. 관리자 화면에서는 불가합니다. 개발에 요청하세요.

**Q. 승인·거절 버튼이 없습니다.**  
A. 의도된 동작입니다. 미분류는 상품 사전 추가 → 재추출로 처리합니다.

**Q. 확인 필요 건수가 사이드바와 다릅니다.**  
A. 사이드바는 **가장 최근** 결과 파일 기준입니다. 확인 필요 탭에서 결과 파일을 바꿔 보세요.
