##### 운영 가이드

###### 1. 이 시스템이 하는 일

신용평가서 PDF에서 **신용등급**과 **주요 재무지표**를 읽어 결과(Excel, JSON, DB)로 남깁니다.  
상품 이름은 **상품 사전**(표준 상품 ↔ PDF에 적힌 원문 표현)에 맞춰 붙입니다.  
사전에 없는 표현·등급이 애매한 건·파일이 깨진 건은 **확인 필요**에 모입니다.  
**Excel 다운로드**에는 분류에 **성공한 건만** 들어갑니다.

###### 2. 일상 운영 루프

1. 신평서 PDF 추출을 실행한다. (결과 파일이 생김)
2. 왼쪽 **새로고침** 후 **결과 조회**에서 성공·부분성공·실패를 본다.
3. **확인 필요**에서 예외 유형을 확인한다.
4. **미분류 상품**이면 **상품 사전**에 원문 표현을 넣고 **추가**한다.
5. 같은 PDF를 **다시 추출**한 뒤, 결과에 반영됐는지 확인한다.
6. 필요하면 **결과 조회**에서 Excel을 내려받는다.

###### 3. 탭별 사용법

| 탭 | 하는 일 |
|----|---------|
| 결과 조회 | 신용등급 행 선택 시 재무지표 확인 가능, `Excel 다운로드` 시 전체 데이터 다운로드 |
| 확인 필요 | 실패, 오류, 조치 필요 항목 목록 (확인용) |
| 상품 사전 | 상품분류 행 선택 시 현재 등록된 원문표현 확인 가능, 새 원문표현 **추가** 또는 **삭제** |
| 운영 가이드 | 비개발자 유지보수 및 운영 가이드라인 |

왼쪽 사이드바에서 PDF를 올리고 **테스트 추출**하면 결과 조회·확인 필요에 `result_test`로 보입니다. '확인 필요 N건'은 가장 최근 결과 파일 기준입니다.

###### 4. 확인 필요 — 예외별 조치

| 유형 | 어떻게 하면 되나요 |
|------|-------------------|
| 미분류 상품 | **상세**에 나온 원문표현 복사 → **상품 사전**에서 맞는 상품 선택 후 **추가** → 재추출 |
| 신용등급 모호/충돌 | 원문 PDF를 보고 업무에서 수기로 보완. 같은 문제가 반복되면 개발 요청 |
| 재무지표 없음 | 해당 신평사 자료에 표가 없거나 읽히지 않은 경우. 수기 보완 또는 개발 요청 |
| 파일/텍스트/구조 오류 | PDF를 다시 받거나, 손상·암호 여부를 확인한 뒤 추출을 다시 실행 |

###### 5. 상품 사전 — 주의사항

1. 위 **상품분류**에서 상품을 하나 고릅니다.
2. 아래 **원문라벨**에 PDF에 적힌 표현을 띄어쓰기까지 **그대로** 입력합니다. (메모는 선택)
3. `추가`를 클릭하면 새로 등록됩니다.
4. 내가 추가한 목록만 `삭제`할 수 있습니다. 기본 목록은 삭제할 수 없습니다.
5. 사전을 바꾼 뒤에는 **반드시 재추출**해야 결과에 반영됩니다.

같은 표현을 두 번 넣거나, 다른 상품에 이미 있는 표현을 넣으면 저장되지 않습니다. 메시지를 읽고 라벨을 확인하세요.

###### 6. 혼자 가능 vs 개발 요청

**이 화면에서 가능**

- 추출 결과 확인, Excel 다운로드
- 상품 사전에 원문표현 추가·삭제
- 실패, 오류, 조치 필요 현황 확인

**개발에 요청**

- 9종 외 새 표준 상품 만들기  
- 기존 원문표현 목록을 고치거나 지우기  
- 추출·등급 판정 방식 자체 변경  
- 같은 파일 오류가 계속 반복될 때
- 원화채권 외, 구조화금융 등 다른 형태의 신평서 추출 모듈 추가

요청할 때 함께 알려 주면 빠른 것: 문제 PDF, 결과 파일 이름, 회사명, 확인 필요에 나온 유형·원문 라벨.

###### 7. FAQ

**Q. Excel에 없는 회사가 확인 필요에는 있습니다.**  
A. Excel에는 **분류 성공**한 건만 들어갑니다. 미분류·실패는 확인 필요에서 처리한 뒤 재추출하세요.

**Q. 상품 사전에 넣었는데 결과가 그대로입니다.**  
A. **추가**로 저장한 다음, 해당 PDF를 **다시 추출**해야 반영됩니다.

**Q. PDF를 다시 추출하고 싶습니다.**  
A. 사이드바에서 PDF를 올린 뒤 **테스트 추출**을 누르거나, PDF를 입력 폴더에 넣은 뒤 서버 PC에서 **run_extract.bat**을 더블클릭하세요.

**Q. 잠긴 라벨을 지우고 싶습니다.**  
A. 이 화면에서는 할 수 없습니다. 개발에 요청하세요.

**Q. 신용등급 표를 골랐는데 재무지표가 비어 있습니다.**  
A. 그 신평사·회사에서 표를 못 읽었거나 원문에 없을 수 있습니다. 확인 필요의 **재무지표 없음**도 함께 보세요.

**Q. 확인 필요 건수가 사이드바와 다릅니다.**  
A. 사이드바는 **가장 최근** 결과 파일 기준입니다. 확인 필요 탭의 **결과 파일**이 같은지 확인하세요.
